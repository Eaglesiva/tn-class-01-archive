### I. சரியான தெரிவைத் தேர்ந்தெடுத்தல்
*சான்று: பாடநூல் பக்கங்கள் 55, 56, 58*

1. கைதட்டுதல் ஒலியில் '1, 1, 1' எனத் தொடரும் அமைப்பிற்கு அடுத்ததாக வருவது எது?
   - (A) 1
   - (B) 5
   - (C) 9
   - (D) 0

2. மேசையில் தட்டும் ஒலி அமைப்பு '1, 2, 1, 2' எனில், அடுத்த முறை தட்ட வேண்டிய எண்ணிக்கை யாது?
   - (A) 1
   - (B) 3
   - (C) 4
   - (D) 0

3. சிவப்பு, நீலம், சிவப்பு, நீலம் என்ற வண்ண அமைப்பில் அடுத்து வரும் வண்ணம் எது?
   - (A) சிவப்பு
   - (B) பச்சை
   - (C) மஞ்சள்
   - (D) கருப்பு

4. வட்டம், சதுரம், வட்டம், சதுரம் என்ற வடிவ அமைப்பில் அடுத்து வரும் வடிவம் எது?
   - (A) வட்டம்
   - (B) முக்கோணம்
   - (C) செவ்வகம்
   - (D) நட்சத்திரம்

### II. கோடிட்ட இடங்களை நிரப்புக
*சான்று: பாடநூல் பக்கங்கள் 56, 58*

1. கைதட்டல் அமைப்பை நிறைவு செய்க: 2, 2, 2, _______, 2.
2. வண்ண அமைப்பை நிறைவு செய்க: பச்சை, மஞ்சள், பச்சை, _______.
3. எண் அமைப்பு: 1, 2, 1, 2, 1, _______.
4. வடிவம்: △, ◯, △, ◯, _______.

### III. பொருத்துக
*சான்று: பாடநூல் பக்கங்கள் 55, 57 — இயற்கை மற்றும் ஒலி அமைப்புகள்*

| பகுதி 'அ' (அமைப்பு வகை) | பகுதி 'ஆ' (எடுத்துக்காட்டு) |
| :--- | :--- |
| 1. கைதட்டல் ஒலி அமைப்பு | (A) சிவப்பு, மஞ்சள், சிவப்பு, மஞ்சள் |

| 4. வடிவ அமைப்பு | (D) சதுரம், வட்டம், சதுரம், வட்டம் |

### IV. சுருக்கமான வினாக்கள்
*சான்று: பாடநூல் பக்கம் 59*

1. உனக்குப் பிடித்த இரண்டு வண்ணங்களைப் பயன்படுத்தி ஓர் எளிய வண்ண அமைப்பை உருவாக்குக.
2. கைதட்டி இரண்டு விதமான ஒலி அமைப்புகளை வெளிப்படுத்துக.
