### I. சரியான தெரிவைத் தேர்ந்தெடுத்தல்
*சான்று: பாடநூல் பக்கங்கள் 5 முதல் 11 வரை — ஒப்பீடுகள்*

1. மரத்தின் உச்சியில் அமர்ந்திருக்கும் பறவையைக் குறிக்கும் சொல் எது?
   - (A) உச்சி
   - (B) அடி
   - (C) அடியில்
   - (D) வெளியே

2. கூண்டுக்குள்ளே இருக்கும் கிளியின் இருப்பிடத்தைக் குறிக்கும் சொல் எது?
   - (A) உள்ளே
   - (B) வெளியே
   - (C) கீழே
   - (D) தொலைவில்

3. மேசையின் மீது வைக்கப்பட்டுள்ள புத்தகத்தின் நிலையைக் குறிப்பது எது?
   - (A) மேல்
   - (B) அடியில்
   - (C) வெளியே
   - (D) தொலைவில்

4. வானத்தில் மேலே பறக்கும் விமானத்தைக் குறிக்கும் சொல் எது?
   - (A) மேலே
   - (B) கீழே
   - (C) அடியில்
   - (D) உள்ளே

5. பள்ளிக்கு மிக அருகில் உள்ள மரத்தைக் குறிக்கும் சொல் எது?
   - (A) அருகில்
   - (B) தொலைவில்
   - (C) உச்சி
   - (D) உள்ளே

6. தர்பூசணி மற்றும் எலுமிச்சையை ஒப்பிடும்போது, அளவில் பெரியது எது?
   - (A) தர்பூசணி
   - (B) எலுமிச்சை
   - (C) இரண்டும் சமம்
   - (D) கூற இயலாது

### II. கோடிட்ட இடங்களை நிரப்புக
*சான்று: பாடநூல் பக்கங்கள் 6, 7, 10, 11*

1. சறுக்கு மரத்தின் உச்சிக்கு எதிர்ச் சொல் _______ ஆகும்.
2. வகுப்பறைக்கு வெளியே என்பதற்கு எதிர்ச் சொல் வகுப்பறைக்கு _______ ஆகும்.
3. பூனை மேசைக்கு _______ படுத்திருக்கிறது. (மேல் / அடியில்)
4. பேருந்து நிறுத்தத்திற்கு _______ நிற்கும் மகிழுந்து. (அருகில் / தொலைவில்)
5. யானை பெரிய விலங்கு, முயல் _______ விலங்கு.
6. பந்து தரைக்கு _______ உருண்டு செல்கிறது.

### III. பொருத்துக
*சான்று: பாடநூல் பக்கங்கள் 5, 12 — கலைச்சொற்கள் மற்றும் வடிவங்கள்*

பொருத்தமான எதிர்ச்சொற்கள் / ஒப்பீடுகளைப் பொருத்துக:

| பகுதி 'அ' (சொல்) | பகுதி 'ஆ' (எதிர்ச் சொல்) |
| :--- | :--- |
| 1. உச்சி | (A) வெளியே |
| 2. உள்ளே | (B) அடி |
| 3. மேலே | (C) சிறியது |
| 4. அருகில் | (D) கீழே |
| 5. பெரியது | (E) தொலைவில் |

### IV. சிந்திக்க வினாக்கள்
*சான்று: பாடநூல் பக்கங்கள் 8, 11*

1. உன் வகுப்பறையில் உன் மேசையின் மேல் உள்ள இரு பொருள்களின் பெயர்களைக் கூறுக.
2. உன் பள்ளி வளாகத்திற்கு உள்ளே உள்ள விளையாட்டுத் திடலைக் குறிப்பிடுக.
3. உனக்கு அருகில் உள்ள நண்பரின் பெயரைக் கூறுக.
