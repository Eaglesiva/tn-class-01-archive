### I. சரியான தெரிவைத் தேர்ந்தெடுத்தல்
*சான்று: பாடநூல் பக்கங்கள் 44 முதல் 51 வரை*

1. இரு பென்சில்களில் அதிக நீளம் கொண்ட பென்சிலைக் குறிக்கும் சொல் எது?
   - (A) நீளமானது
   - (B) குட்டையானது
   - (C) தடிமனானது
   - (D) இலேசானது

2. வாழை மரம் மற்றும் தென்னை மரத்தை ஒப்பிடும்போது உயரமானது எது?
   - (A) தென்னை மரம்
   - (B) வாழை மரம்
   - (C) இரண்டும் சமம்
   - (D) கூற இயலாது

3. தர்பூசணி மற்றும் ஆப்பிளை ஒப்பிடும்போது அதிக கனமானது எது?
   - (A) தர்பூசணி
   - (B) ஆப்பிள்
   - (C) இரண்டும் சமம்
   - (D) கூற இயலாது

4. கைவிரல்களை விரித்து கட்டைவிரலின் நுனியிலிருந்து சிறுவிரலின் நுனி வரை அளக்கும் முறைக்கு என்ன பெயர்?
   - (A) சான் (Hand span)
   - (B) முழம் (Cubit)
   - (C) காலடி (Foot span)
   - (D) தப்படி (Pace)

5. முழங்கையிலிருந்து நடுவிரலின் நுனி வரை உள்ள நீளத்திற்கு என்ன பெயர்?
   - (A) முழம் (Cubit)
   - (B) சான் (Hand span)
   - (C) காலடி (Foot span)
   - (D) தப்படி (Pace)

6. ஒரு வாளி மற்றும் ஒரு குவளையை ஒப்பிடும்போது அதிக நீர் பிடிக்கும் பாத்திரம் எது?
   - (A) வாளி
   - (B) குவளை
   - (C) இரண்டும் சமம்
   - (D) எதுவும் இல்லை

### II. கோடிட்ட இடங்களை நிரப்புக
*சான்று: பாடநூல் பக்கங்கள் 44, 46, 50, 51*

1. கரும்பு நீளமானது, கத்தரிக்கோல் _______ ஆகும்.
2. யானை கனமானது, இறகு _______ ஆகும்.
3. மேசையின் நீளத்தை அளக்க நாம் _______ ஐப் பயன்படுத்தலாம். (சான் / காலடி)
4. வகுப்பறையின் நீளத்தை அளக்க நாம் _______ அல்லது தப்படியைப் பயன்படுத்தலாம்.
5. அதிகக் கொள்ளளவு கொண்ட பாத்திரம்: _______. (குடம் / டம்ளர்)

### III. பொருத்துக
*சான்று: பாடநூல் பக்கங்கள் 47, 51 — அளவீடுகளும் உறுப்புகளும்*

| பகுதி 'அ' (அளவை முறை) | பகுதி 'ஆ' (பயன்படும் உடல் உறுப்பு) |
| :--- | :--- |
| 1. சான் | (A) முழங்கை முதல் நடுவிரல் வரை |
| 2. காலடி | (B) விரல்களை விரித்த கை |
| 3. முழம் | (C) ஒரு காலின் பாதம் |
| 4. தப்படி | (D) இரு கால்களுக்கு இடைப்பட்ட நடை இடைவெளி |

### IV. சுருக்கமான வினாக்கள்
*சான்று: பாடநூல் பக்கங்கள் 45, 51*

1. திட்டமில்லா அளவைகள் நான்கினைக் குறிப்பிடுக.
2. உன் வகுப்பறை மேசையின் நீளம் உனது கையின் எத்தனை சான் உள்ளது என அளந்து கூறுக.
3. கனமான பொருள், இலேசான பொருள் ஒவ்வொன்றிற்கு எடுத்துக்காட்டு தருக.
