### I. சரியான தெரிவைத் தேர்ந்தெடுத்தல்
*சான்று: பாடநூல் பக்கங்கள் 25 முதல் 34 வரை*

1. அடர்ந்த மரங்களும் பல காட்டு விலங்குகளும் வாழும் நிலப்பரப்பு எது?
   - (A) காடு (Forest)
   - (B) நகரம்
   - (C) விளையாட்டு மைதானம்
   - (D) பாலைவனம்

2. மக்கள் பயிர்த்தொழில் செய்து வாழும் தட்டையான நிலப்பரப்பு எது?
   - (A) சமவெளி (Plains)
   - (B) பனிமலை
   - (C) பெருங்கடல்
   - (D) குகை

3. குளிர்ந்த காற்றும் தேயிலைத் தோட்டங்களும் நிறைந்த உயர்ந்த நிலப்பரப்பு எது?
   - (A) மலை (Hill / Mountain)
   - (B) குளம்
   - (C) கடற்கரை
   - (D) ஆறு

4. உவர்நீர் (உப்பு நீர்) கொண்ட மிகப்பெரிய நீர்நிலை எது?
   - (A) கடல்
   - (B) குட்டை
   - (C) கிணறு
   - (D) சிற்றாறு

5. சுற்றுப்புறத்தைத் தூய்மையாக வைத்திருக்க நாம் குப்பைகளை எங்கு போட வேண்டும்?
   - (A) குப்பைத் தொட்டியில்
   - (B) தெருவில்
   - (C) ஆற்றில்
   - (D) வகுப்பறை தரையில்

### II. கோடிட்ட இடங்களை நிரப்புக
*சான்று: பாடநூல் பக்கங்கள் 27, 30, 34*

1. காடுகள் நமக்குத் தூய்மையான காற்றையும், குளிர்ந்த _______ தருகின்றன. (மழையையும் / வெயிலையும்)
2. ஆற்று நீர் சுவைப்பதற்கு _______ இருக்கும். (இனிப்பாக / உப்பாக)
3. மலைகளில் பயிரிடப்படும் முக்கியப் பயிர் _______ ஆகும். (தேயிலை / கரும்பு)
4. கடல் நீரில் பல வகை வண்ண _______ வாழ்கின்றன. (மீன்கள் / பறவைகள்)
5. பிளாஸ்டிக் கழிவுகளை நிலத்திலோ நீரிலோ _______ கூடாது. (எறியக் / போடக்)

### III. பொருத்துக (நில அமைப்புகளும் கூறுகளும்)
*சான்று: பாடநூல் பக்கங்கள் 28, 32*

| பகுதி 'அ' (நில அமைப்பு) | பகுதி 'ஆ' (தனித்துவமான அம்சம்) |
| :--- | :--- |
| 1. காடு | (A) நெல் வயல்கள், உழவுத்தொழில் |
| 2. சமவெளி | (B) படகுகள், அலைகள் |
| 3. மலை | (C) அடர்ந்த மரங்கள், விலங்குகள் |
| 4. கடல் | (D) குளிர்ச்சி, கொண்டை ஊசி வளைவுகள் |

### IV. சுருக்கமான வினாக்கள்
*சான்று: பாடநூல் பக்கங்கள் 29, 34*

1. நமது சுற்றுச்சூழலில் உள்ள மூன்று முக்கிய நிலப்பரப்புகளைக் குறிப்பிடுக.
2. காடுகளில் வாழும் இரண்டு விலங்குகளின் பெயர்களைக் கூறுக.
3. சுற்றுப்புறத்தை சுத்தமாக வைத்திருக்க ஒரு நற்பழக்கத்தைக் குறிப்பிடுக.
