### I. சரியான தெரிவைத் தேர்ந்தெடுத்தல்
*சான்று: பாடநூல் பக்கங்கள் 5 முதல் 18 வரை*

1. நமது உடலுக்கு ஆற்றலையும் நல்ல வளர்ச்சியையும் தருவது எது?
   - (A) சத்தான உணவு
   - (B) தூசி
   - (C) பிளாஸ்டிக்
   - (D) மருந்து மட்டும்

2. தாவரங்களிலிருந்து நமக்குக் கிடைக்கும் உணவுப் பொருள் எது?
   - (A) அரிசி மற்றும் காய்கறிகள்
   - (B) பால்
   - (C) தேன்
   - (D) முட்டை

3. பசு மற்றும் எருமையிடமிருந்து நாம் பெறும் சத்தான திரவ உணவு எது?
   - (A) பால்
   - (B) எண்ணெய்
   - (C) தேன்
   - (D) பழச்சாறு

4. தேனீக்களிடமிருந்து பெறப்படும் இனிப்பான இயற்கை உணவு எது?
   - (A) தேன்
   - (B) சர்க்கரை
   - (C) வெல்லம்
   - (D) நெய்

5. உடலுக்குத் தீங்கு விளைவிக்கும் நொறுக்குத் தீனி எது?
   - (A) பொரித்த பாக்கெட் சிப்ஸ்
   - (B) வேகவைத்த பயறு
   - (C) கொய்யாப்பழம்
   - (D) கீரை சூப்

### II. கோடிட்ட இடங்களை நிரப்புக
*சான்று: பாடநூல் பக்கங்கள் 8, 12, 17*

1. கோழியிடமிருந்து நாம் _______ பெறுகிறோம். (முட்டை / பால்)
2. நாம் உண்ணும் உணவை நன்றாக _______ சாப்பிட வேண்டும். (மென்று / அவசரமாக)
3. உணவை வீணாக்காமல் _______ வேண்டும். (சாப்பிட / எறிய)
4. கேழ்வரகு, கம்பு ஆகியவை உடலுக்கு வலிமை தரும் _______ ஆகும். (தானியங்கள் / பழங்கள்)
5. சாப்பிடுவதற்கு முன்பும் பின்பும் கைகளை _______ கழுவ வேண்டும். (சுத்தமாக / சாதாரணமாக)

### III. பொருத்துக (உணவுப் பொருட்களின் ஆதாரங்கள்)
*சான்று: பாடநூல் பக்கங்கள் 10, 14*

பகுதி 'அ' வைப் பகுதி 'ஆ' உடன் பொருத்துக:

| பகுதி 'அ' (உணவுப் பொருள்) | பகுதி 'ஆ' (ஆதாரம்) |
| :--- | :--- |
| 1. ஆப்பிள், மாம்பழம் | (A) தேனீக்கள் |
| 2. பால், தயிர் | (B) கோழி |
| 3. முட்டை | (C) தாவரங்கள் |
| 4. தேன் | (D) பசு |

### IV. சுருக்கமான வினாக்கள்
*சான்று: பாடநூல் பக்கங்கள் 15, 18*

1. தாவரங்களிலிருந்து பெறப்படும் இரண்டு உணவுப் பொருள்களின் பெயர்களை எழுதுக.
2. விலங்குகளிடமிருந்து பெறப்படும் இரண்டு உணவுப் பொருள்களின் பெயர்களைக் குறிப்பிடுக.
3. ஆரோக்கியமான உணவுப் பழக்கவழக்கங்கள் இரண்டினைக் கூறுக.
