### I. சரியான தெரிவைத் தேர்ந்தெடுத்தல்
*சான்று: பாடநூல் பக்கங்கள் 29 முதல் 42 வரை*

1. நிலத்தில் உறுதியாக நிற்கும் பெரிய வலிமையான தாவரம் எது?
   - (A) மரம் (Tree)
   - (B) புல்
   - (C) கீரை
   - (D) கொடி

2. கீழ்க்காண்பனவற்றில் நறுமணம் மிக்க மலர் எது?
   - (A) மல்லிகை
   - (B) பூசணிப்பூ
   - (C) வாழைப்பூ
   - (D) தென்னம்பூ

3. வைட்டமின் சத்துக்கள் நிறைந்த இயற்கை உணவு எது?
   - (A) பழங்கள்
   - (B) பிளாஸ்டிக் மிட்டாய்
   - (C) துரித உணவு
   - (D) குளிர்பானம்

4. நமது தேசிய மலர் எது?
   - (A) தாமரை
   - (B) ரோஜா
   - (C) மல்லிகை
   - (D) செம்பருத்தி

5. கீழ்க்காண்பனவற்றில் பச்சையாக உண்ணக்கூடிய காய் எது?
   - (A) கேரட்
   - (B) உருளைக்கிழங்கு
   - (C) சேனைக்கிழங்கு
   - (D) கத்தரிக்காய்

### II. கோடிட்ட இடங்களை நிரப்புக
*சான்று: பாடநூல் பக்கங்கள் 31, 36, 41*

1. மரங்கள் நமக்குத் தூய்மையான _______ தருகின்றன. (காற்று / மண்)
2. வாழை மரத்தின் இலை மிகவும் _______ இலை ஆகும். (பெரிய / சிறிய)
3. செம்பருத்தி மலர் பொதுவாக _______ நிறத்தில் காணப்படும். (சிவப்பு / நீலம்)
4. மாம்பழம் ஒரு சுவையான _______ ஆகும். (பழம் / காய்)
5. தாவரங்கள் வளர்வதற்கு மண், நீர் மற்றும் _______ தேவை. (சூரிய ஒளி / இருள்)

### III. பொருத்துக (இயற்கைக் கொடைகள்)
*சான்று: பாடநூல் பக்கங்கள் 34, 38, 41*

| பகுதி 'அ' (தாவரப் பகுதி / பொருள்) | பகுதி 'ஆ' (எடுத்துக்காட்டு) |
| :--- | :--- |
| 1. மரம் | (A) வெண்டை, கத்தரி |
| 2. கொடி | (B) ஆப்பிள், மாம்பழம் |
| 3. பழம் | (C) ஆலமரம், வேப்பமரம் |
| 4. காய் | (D) பாகற்காய் கொடி |

### IV. சுருக்கமான வினாக்கள்
*சான்று: பாடநூல் பக்கங்கள் 35, 42*

1. உனக்குப் பிடித்த இரண்டு பழங்களின் பெயர்களை எழுதுக.
2. சமையலுக்குப் பயன்படும் இரண்டு காய்கறிகளின் பெயர்களைக் குறிப்பிடுக.
3. அழகிய நறுமணமுடைய இரண்டு பூக்களின் பெயர்களை எழுதுக.
