### I. சரியான தெரிவைத் தேர்ந்தெடுத்தல்
*சான்று: பாடநூல் பக்கங்கள் 5 முதல் 14 வரை*

1. கீழ்க்காண்பனவற்றில் உயிருள்ள பொருள் எது?
   - (A) செடி
   - (B) கல்
   - (C) நாற்காலி
   - (D) புத்தகம்

2. உயிரற்ற பொருட்களுக்கு எது தேவைப்படாது?
   - (A) உணவு
   - (B) காற்று
   - (C) நீர்
   - (D) இவை அனைத்தும்

3. தானாக ஓரிடத்திலிருந்து மற்றொரு இடத்திற்கு நகரக்கூடியது எது?
   - (A) நாய்
   - (B) மர நாற்காலி
   - (C) மேசை
   - (D) கல்

4. மனிதனால் உருவாக்கப்பட்ட உயிரற்ற பொருளுக்கு எடுத்துக்காட்டு எது?
   - (A) மிதிவண்டி (Bicycle)
   - (B) ஆறு
   - (C) மலை
   - (D) சூரியன்

5. இயற்கையிலேயே காணப்படும் உயிரற்ற பொருள் எது?
   - (A) பாறை
   - (B) மகிழுந்து
   - (C) எழுதுகோல்
   - (D) சட்டை

### II. கோடிட்ட இடங்களை நிரப்புக
*சான்று: பாடநூல் பக்கங்கள் 6, 8, 12*

1. உயிருள்ள பொருள்கள் வளரும் தன்மை _______ உடையவை. (உடையவை / அற்றவை)
2. மர நாற்காலி ஒரு _______ பொருள் ஆகும். (உயிரற்ற / உயிருள்ள)
3. பசு உணவு உண்கிறது; எனவே அது _______ பொருள். (உயிருள்ள / உயிரற்ற)
4. உயிருள்ள பொருள்கள் சுவாசிக்க காற்று _______. (தேவை / தேவையில்லை)
5. ஆறு, மலை, மண் ஆகியவை _______ உருவாக்கிய உயிரற்ற பொருள்கள். (இயற்கை / மனிதன்)

---

### III. பொருத்துக
*சான்று: பாடநூல் பக்கங்கள் 7, 10, 13*

பகுதி 'அ' வைப் பகுதி 'ஆ' உடன் பொருத்துக:

| பகுதி 'அ' (பொருள்) | பகுதி 'ஆ' (வகை) |
| :--- | :--- |
| 1. மரக்கன்று | (A) மனிதனால் செய்யப்பட்ட உயிரற்ற பொருள் |
| 2. சூரியன் | (B) சுவாசிக்கும் உயிருள்ள பொருள் |
| 3. மட்டைப்பந்து (Bat) | (C) இயற்கை உயிரற்ற பொருள் |
| 4. சிறுவன் | (D) வளரும் தாவர உயிருள்ள பொருள் |

### IV. சுருக்கமான வினாக்கள்
*சான்று: பாடநூல் பக்கங்கள் 8, 14*

1. உயிருள்ள பொருள்களின் இரண்டு முக்கியப் பண்புகளைக் குறிப்பிடுக.
2. உன் வீட்டில் உள்ள ஏதேனும் மூன்று உயிரற்ற பொருள்களின் பெயர்களை எழுதுக.
3. இயற்கையான உயிரற்ற பொருள்கள் இரண்டின் பெயர்களைக் குறிப்பிடுக.
