### I. சரியான தெரிவைத் தேர்ந்தெடுத்தல்
*சான்று: பாடநூல் பக்கங்கள் 15 முதல் 28 வரை*

1. வண்ணங்களையும் அழகான காட்சிகளையும் காண நாம் பயன்படுத்தும் உறுப்பு எது?
   - (A) கண்
   - (B) காது
   - (C) மூக்கு
   - (D) நாக்கு

2. இனிப்பான சுவையை அறிய உதவும் உறுப்பு எது?
   - (A) நாக்கு
   - (B) மூக்கு
   - (C) தோல்
   - (D) காது

3. பாடல்களையும் ஒலிகளையும் கேட்க உதவும் புலனுறுப்பு எது?
   - (A) காது
   - (B) கண்
   - (C) கை
   - (D) நாக்கு

4. ஒரு பொருள் சூடாக இருக்கிறதா அல்லது குளிர்ச்சியாக இருக்கிறதா என்பதை உணர உதவுவது எது?
   - (A) தோல்
   - (B) காது
   - (C) மூக்கு
   - (D) கண்

5. பந்தினை உதைத்து விளையாட நாம் பயன்படுத்தும் உறுப்பு எது?
   - (A) கால்
   - (B) காது
   - (C) வாய்
   - (D) மூக்கு

### II. கோடிட்ட இடங்களை நிரப்புக
*சான்று: பாடநூல் பக்கங்கள் 18, 21, 26*

1. நமக்கு வாசனை அறிய உதவும் உறுப்பு _______ ஆகும்.
2. நாம் உணவு உண்பதற்கு முன் கைகளை சோப்பு போட்டு _______ வேண்டும்.
3. நம் முகத்தில் அமைந்துள்ள கண்களின் எண்ணிக்கை _______.
4. நாம் எழுதுவதற்கும் பொருட்களைப் பிடிப்பதற்கும் _______ பயன்படுத்துகிறோம்.
5. நாள்தோறும் காலையிலும் இரவிலும் பற்களைத் _______ வேண்டும்.

### III. பொருத்துக (புலனுறுப்புகளும் செயல்களும்)
*சான்று: பாடநூல் பக்கங்கள் 20, 22*

| பகுதி 'அ' (புலனுறுப்பு) | பகுதி 'ஆ' (செயல்பாடு) |
| :--- | :--- |
| 1. கண் | (A) வாசனையை முகர்தல் |
| 2. காது | (B) தொடு உணர்வை அறிதல் |
| 3. மூக்கு | (C) காட்சிகளைப் பார்த்தல் |
| 4. நாக்கு | (D) ஒலிகளைக் கேட்டல் |
| 5. தோல் | (E) சுவையை அறிதல் |

### IV. சுருக்கமான வினாக்கள்
*சான்று: பாடநூல் பக்கங்கள் 23, 28*

1. நமது உடலின் ஐந்து புலனுறுப்புகளின் பெயர்களைக் குறிப்பிடுக.
2. கைகளைப் பயன்படுத்தி நாம் செய்யும் மூன்று செயல்களைக் கூறுக.
3. ஆரோக்கியமாக வாழ நாம் கடைப்பிடிக்க வேண்டிய இரண்டு நல்ல பழக்கங்களைக் குறிப்பிடுக.
